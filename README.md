# ExactLedger

ExactLedger is a billing and settlement engine for marketplaces, featuring precise multi-party payment splits, double-entry accounting, configurable fees, escrow, refunds, and automated reconciliation.

For local PostgreSQL and API startup, follow the [Docker Compose setup](docs/development/local-docker.md).

For versioned regional rules and corporate fee/escrow profiles, see the [configuration guide](docs/development/knowledge-configuration.md).
